# FANUC 铣削编程助手（W版）

《数控铣削编程与加工（FANUC系统）》配套的教学工具，面向江苏联合职业技术学院惠山中专办学点 522142 / 522143 班。

**在线使用**：https://fanuc-milling-w.app.workbuddy.host/app.html?sharecode=OTD3JQJQPI

## 是什么

单文件 Web 应用（`app.html`，零构建、零依赖），11 个面板覆盖铣削编程教学全流程：

| 面板 | 作用 |
|---|---|
| G/M 代码速查 | 51 条指令，可搜索、按类筛选 |
| 程序编辑器 | 9 个工艺模板 + 13 项快捷输入 + 编辑器 |
| 参数计算 | n / F / Q / Pc / Pm，材料联动 |
| 程序解释 | 逐行翻译，地址字按上下文释义 |
| 程序校验 | 43 条规则（21 E / 16 W / 6 I） |
| 刀轨演示 | 2D 轨迹、分步、刀补偏置、代码联动、尺寸核对 |
| 批量批改 | 多份打分 + 问题清单 + CSV |
| 找错练习 | 10 种变异注入 + 交卷对答案 |
| AI 智能编程 | 图纸 → 图元 → SVG → 程序；也可直接描述需求 |
| 刀具库 | T 号 / 名称 / 直径 / 刃数 / 补半径一张表，三处下拉联动 |
| 帮助 | 内嵌完整使用说明（含插图） |

## 图纸转程序的做法

```
图纸(SVG/PNG/JPG) → 几何图元(line/arc/circle) → 本地合成 SVG → 轮廓 → FANUC 程序
                          ↑ 模型只负责看懂图        ↑ 本地确定性代码
```

- 模型只输出**图元**，不输出点列；程序由本地生成器按固定口径拼装（G41+D、外顺内逆、分层均分、孔逐孔判钻/铣）。
- 三道校验：S01 断口（提示）、S02 自交（阻断）、S03 尺寸一致（提示）。
- **断口不补线**：断就断，各段独立加工，段间 `G00 Z安全高度` 抬刀再跳，刀轨图上用红圈标出缺口位置与大小。
- 合成出的 SVG 可下载、可外部编辑、可重新上传。

## 开发历程

从 v1.0.0 到 v1.18.4：16 天、43 个版本、100 次提交，按功能主线归并为 **6 个阶段、24 个任务**。

![开发历程](docs/img/lifecycle.png)

| 阶段 | 版本 | 主要任务 |
|---|---|---|
| 搭起骨架 | v1.0.0 | 速查 / 模板 / 计算 / 解释 / AI 五个模块 |
| 补上核心能力 | v1.1–1.5 | 校验器 43 条、刀轨引擎、批改台、代码联动、帮助面板、发布链路 |
| 打通图纸编程 | v1.6–1.10 | 图元 → SVG → 程序全链路、断口处理、刀具库 |
| 两次界面改版 | v1.11–1.12 | 设计令牌、胶囊导航、靛紫单列、手机适配 |
| 教学增强与提速 | v1.13–1.18.3 | 演示案例、三个工艺样例、快捷输入、刀轨标注、AI 提速 |
| 收口打磨 | v1.18.4 | 底色调整、修「标坐标」开关、全模块冒烟 |

三处关键转折：

1. **v1.7.0 图纸链路重构** —— 模型只报图元、本地合成 SVG 再生成程序，闭合 / 自交 / 尺寸从“看截图猜”变成可校验的代码，bug 数量由此下降。
2. **v1.6.2 入口拆分** —— `index.html` 只做转发，分享链接永久固定，发版不用再通知学生换地址。
3. **v1.18.2 AI 提速** —— 慢的根因不是网络，而是默认取了模型列表第一个 `auto` 路由模型；改为按速度排序后首字 150s → 1.0s。

统计口径：43 个版本、100 次提交、29 个发版快照、453 项断言、137 项浏览器冒烟、单文件 27.8 KB → 1.53 MB。逐版本细节见 [`CHANGELOG.md`](CHANGELOG.md)。

## 本地打开

直接双击 `app.html`。绝大多数功能纯本地运算；只有 AI 生成与位图识别需要联网（且只在官方分享链接下可用，云服务密钥按 Origin 校验）。
