# FANUC 铣削编程助手（W版）

《数控铣削编程与加工（FANUC系统）》配套的教学工具，面向江苏联合职业技术学院惠山中专办学点 522142 / 522143 班。

**在线使用**：https://fanuc-milling-w.app.workbuddy.host/app.html?sharecode=OTD3JQJQPI

## 是什么

单文件 Web 应用（`app.html`，零构建、零依赖），10 个面板覆盖铣削编程教学全流程：

| 面板 | 作用 |
|---|---|
| G/M 代码速查 | 51 条指令，可搜索、按类筛选 |
| 程序编辑器 | 6 个标准模板 + 编辑器 |
| 参数计算 | n / F / Q / Pc / Pm，材料联动 |
| 程序解释 | 逐行翻译，地址字按上下文释义 |
| 程序校验 | 43 条规则（21 E / 16 W / 6 I） |
| 刀轨演示 | 2D 轨迹、分步、刀补偏置、代码联动、尺寸核对 |
| 批量批改 | 多份打分 + 问题清单 + CSV |
| 找错练习 | 10 种变异注入 + 交卷对答案 |
| AI 智能编程 | 图纸 → 图元 → SVG → 程序；也可直接描述需求 |
| 帮助 | 内嵌完整使用说明（含插图） |

## 图纸转程序的做法

```
图纸(SVG/PNG/JPG) → 几何图元(line/arc/circle) → 本地合成 SVG → 轮廓 → FANUC 程序
                          ↑ 模型只负责看懂图        ↑ 本地确定性代码
```

- 模型只输出**图元**，不输出点列；程序由本地生成器按固定口径拼装（G41+D、外顺内逆、分层均分、孔逐孔判钻/铣）。
- 三道校验：S01 断口（提示）、S02 自交（阻断）、S03 尺寸一致（提示）。
- **断口不补线**：断就断，各段独立加工，段间 `G00 Z安全高度` 抬刀再跳，刀轨图上用红圈标出缺口位置与大小。
- 合成出的 SVG 可下载、可外部编辑、可重新上传。

## 本地打开

直接双击 `app.html`。绝大多数功能纯本地运算；只有 AI 生成与位图识别需要联网（且只在官方分享链接下可用，云服务密钥按 Origin 校验）。
